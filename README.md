This repository contains 3 completed Python internship tasks:

Task Automation with Python Scripts
Requirements
Python 3.8+
No external packages are required.
How to run
Task 1
python task1_hangman.py
Task 2
python task2_stock_portfolio.py
Task 3
python task3_file_automation.py
Task 3
The automation script moves .jpg files from a source folder into a destination folder. It creates the destination folder if needed.
Example:
python task3_file_automation.py "input_folder" "jpg_files"
The project is intentionally simple and beginner-friendly, using Python fundamentals such as loops, conditionals, functions, dictionaries, lists, strings, os, shutil, and file handling.
